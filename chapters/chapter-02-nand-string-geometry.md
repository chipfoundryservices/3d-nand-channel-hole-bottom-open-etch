# Chapter 2: NAND String Geometry and Feature Scaling

*In Development*

## Overview

This chapter covers the detailed geometry of 3D NAND strings, including:

- NAND string architecture variations (SLC, MLC, TLC, QLC)
- Layer stacking sequences and spacing evolution
- Feature scaling from 48-layer to 176+ layer stacks
- Thermal stability limits and implications for channel hole etch
- Etch stop mechanisms and selectivity requirements across layers

## Key Sections (Planned)

### 2.1 String Configurations

- Single string vs. array strings
- Series vs. parallel connection topologies
- Charge trap vs. floating gate architectures

### 2.2 Layer Stacking Sequences

- Alternating word line / sacrificial oxide model
- Modern stack with nitride liners and high-k dielectrics
- Layer thickness evolution: 50nm (first-gen) → 15nm (current)

### 2.3 Feature Scaling

- 48-layer generation (2013): 1-2 μm stack height
- 96-layer generation (2016): 3-4 μm stack height
- 176-layer generation (2020): 8-10 μm stack height
- Roadmap: 200+ layers (2025+)

### 2.4 Etch Stop Challenges

- Tungsten/polysilicon contacts
- SiO₂/SiCN interfaces
- Nitride layers as etch barriers

### 2.5 Thermal Stability and Its Etch Implications

- Gate oxide integrity at high temperatures
- Floating gate charge retention during etch
- Temperature limits for each device generation
